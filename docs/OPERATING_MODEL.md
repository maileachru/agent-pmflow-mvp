# Operating Model

PMFlow Codex is not an AI chat assistant.

It is a deterministic PM operating workflow.

## Principle

```text
Meeting
  ↓
Transcript
  ↓
pmflow run-weekly
  ↓
Protocol
Actions
Status
Telegram draft
PPTX
```

## Human Responsibilities

Human PM remains responsible for:

- decisions
- approvals
- communication
- prioritization

## System Responsibilities

PMFlow automates:

- formatting
- extraction
- reporting
- reminders
- presentation generation

## What NOT to do

Do not turn the project into:

- AI platform
- agent swarm
- enterprise orchestration layer
- giant integration hub

Keep the workflow small and reliable.
