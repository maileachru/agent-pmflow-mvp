# Project Structure

```text
pmflow-codex/
│
├── AGENTS.md

├── docs/
├── examples/
├── integrations/
├── meetings/
├── memory/

├── pmflow/

├── templates/

```

## Main Folders

### meetings/inbox

Incoming meeting transcripts or notes.

### memory

Persistent PM artifacts:

- protocols
- decisions
- actions

### outputs

Generated operational outputs:

- status reports
- Telegram drafts
- PPTX files

### skills

Deterministic PM skills used by Codex.

### templates

Markdown templates for generated artifacts.
