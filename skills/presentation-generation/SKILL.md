# Presentation Generation

## Purpose

Generate PowerPoint-ready executive deck.

## Outputs

- `/outputs/presentations/<title>-outline.md`
- `/outputs/presentations/<title>.pptx`

## Slide Contract

Each slide has:

- title
- 3–5 bullets max

## Default Deck

1. Executive Summary
2. Current Status
3. Key Decisions
4. Risks / Blockers
5. Next Steps
6. Decisions Required
